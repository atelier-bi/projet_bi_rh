## 3. Décomposition des travaux

### RHBI-1 — Questions décisionnelles et KPI

Travaux :
- Définir la problématique RH.
- Identifier les utilisateurs cibles.
- Formuler les questions décisionnelles.
- Définir les KPI RH.

Livrables associés : fiche projet, expression du besoin, questions décisionnelles et catalogue KPI.

### RHBI-2 — Documentation des données

Travaux :
- Identifier la source du fichier RH.
- Décrire sa structure.
- Examiner les variables.
- Préparer le dictionnaire des données.

Livrables associés : inventaire, description du dataset, rapport Data Understanding et dictionnaire.

### RHBI-3 — Qualité des données

Travaux :
- Vérifier les valeurs manquantes.
- Rechercher les doublons.
- Identifier les valeurs atypiques.
- Documenter les contrôles réalisés.

Livrable associé : diagnostic de qualité des données.

### RHBI-4 — Exploration Power BI

Travaux :
- Importer le fichier RH dans Power BI.
- Afficher les indicateurs principaux.
- Créer des graphiques exploratoires.
- Documenter les premières étapes Power Query.
- Présenter les constats et les limites.

Livrables associés : L28, L29, L30 et L31.
