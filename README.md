# Projet BI — Analyse des départs des salariés

## Présentation du projet

Ce projet est réalisé dans le cadre du module **Atelier Business Intelligence — Master 2 Business Analytics**.

Il vise à analyser les départs des salariés afin d'aider la direction des ressources humaines à identifier les départements et les profils nécessitant une attention particulière.

## Problématique

Dans quels départements et pour quels profils la direction RH devrait-elle examiner les départs en priorité afin de cibler ses actions de fidélisation ?

## Source des données

- **Dataset :** IBM HR Analytics Employee Attrition & Performance
- **Source :** Kaggle
- **Format :** CSV
- **Volume :** 1 470 salariés et 35 variables
- **Nature :** Données fictives

## Outils utilisés

- Python : exploration et analyse des données
- Google Colab : exécution du notebook
- Pandas : manipulation des données
- Matplotlib et Seaborn : visualisation
- GitHub : versionnement et collaboration
- Power BI : visualisation décisionnelle

## Organisation des fichiers

- `02_Données/carnets/` : notebook Python
- `02_Données/données/` : dataset CSV
- `02_Données/rapports/` : dictionnaire des données

## Reproduire les analyses

1. Télécharger le dataset CSV depuis le dépôt.
2. Ouvrir le notebook dans Google Colab.
3. Exécuter les cellules dans l'ordre.
4. Importer le fichier CSV lorsque Google Colab le demande.
5. Consulter les statistiques, les graphiques et les résultats des contrôles qualité.

## Limites

Le dataset est fictif et ne contient pas d'historique daté. Les résultats permettent d'identifier des associations entre variables, mais pas de démontrer des relations de causalité.
